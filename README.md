# MarkRelay Mail

Multi-domain mail, broadcasts, an email API, and webhooks that run in your own
Cloudflare account.

This repository contains the prebuilt MarkRelay Mail release 0.4.0. It
is generated automatically and published only so that licensed MarkRelay
deployments can install and update it.

**To get MarkRelay, deploy it, or update it, start at
[markrelay.com](https://markrelay.com):**

- [Pricing and licenses](https://markrelay.com/pricing)
- [Documentation](https://markrelay.com/docs)
